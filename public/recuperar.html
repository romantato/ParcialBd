¿Olvidó su contraseña?

Siga estos pasos para recuperar el acceso a su cuenta.

  1. Paso 1

    Usuario

    Solicita la recuperación de contraseña.

  2. Paso 2

    Ingresa correo

    Proporciona el correo registrado en el sistema.

  3. Paso 3

    Sistema verifica usuario

    Se valida que el correo corresponda a un usuario registrado.

  4. Paso 4

    Generación de token temporal

    Se genera un token único para restablecer la contraseña.

  5. Paso 5

    Envío de correo

    Se envía el enlace de recuperación, que incluye el token.

  6. Paso 6

    Usuario accede al enlace

    Al abrirlo, el sistema muestra la pantalla para restablecer la contraseña.

  7. Paso 7

    Nueva contraseña

    Ingresa y confirma la nueva contraseña.

  8. Paso 8

    Actualización en BD

    Se guarda la contraseña y se desactiva el token de recuperación.
